# Folkets Vitensenter

Semester Project 1 for Noroff Front-end Development.

Folkets Vitensenter is a responsive multi-page website for a fictional
community science museum in Nannestad, Norway. The site is designed primarily
for parents and caregivers planning a family visit, while remaining accessible
and engaging for children, teachers, researchers and other visitors.

## Design approach

The visual direction combines a calm Scandinavian interface with engaging
science imagery. The interface uses generous spacing, restrained colours,
rounded forms and clear information hierarchy so that practical visitor
information remains easy to find.

## Accessibility

The project includes:

- Semantic HTML
- Descriptive alternative text
- Keyboard-accessible navigation
- Visible focus states
- Skip-to-content link
- Responsive layouts
- Accessible colour contrast
- `aria-current` for active navigation items

## Performance and validation

The deployed website was tested using Google PageSpeed Insights.

Home:

- Mobile performance: 93
- Desktop performance: 100
- Accessibility: 100
- Best Practices: 100
- SEO: 100

The Exhibitions and Visit pages also scored 93 for mobile performance and
100 for Accessibility, Best Practices and SEO.

HTML and CSS were validated using the W3C/Nu validators.

## Images

Website imagery was sourced from Canva Pro and generated using AI image tools,
then converted to WebP and compressed to below approximately 200 KB per image.

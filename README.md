# Folkets Vitensenter

Responsive multi-page website created for the Noroff Semester Project 1 assignment.

The site is designed for families and children aged 7–15, with a calm Nordic visual style and a strong focus on clear practical information, accessibility and responsive design.

## Built with

- HTML5
- CSS3
- Flexbox
- CSS Grid

No JavaScript or CSS frameworks were used.

## Accessibility and performance

The site uses semantic HTML, descriptive alt text, visible focus states, responsive layouts and optimised WebP images.
